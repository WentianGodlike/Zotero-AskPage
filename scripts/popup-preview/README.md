# 划词弹窗预览

把弹窗的按钮行单独渲染出来，用于肉眼检查布局。

## 为什么需要

弹窗在阅读器的 iframe 里，**插件沙箱内无法预览**；而"输入框太窄"这类问题
单元测试也测不出来。这一行只是 CSS 加固定的 DOM 结构，单独渲染足以判断实际
几何，而且迭代只要几秒，不必走"装插件 + 重启 Zotero"的循环。

样式表直接从 `src/modules/readerPopup.ts` 里读出来，因此预览**不会与线上
样式脱节**。

## 用法

```sh
scripts/popup-preview/run.sh     # 生成并截图
```

产物在 `out/`：`preview.html` 与 `preview.png`。

依赖：`firefox`（无头截图）与 Python 3.8+。`preview.html` 也可以直接用浏览器打开。

## 定稿依据

输入框与弹窗的宽度是**并排渲染 340 / 380 / 420 三种取值对比后**选定的
（380px）：既能让占位文字完整显示，又不至于大到遮住下方正文。
